# 「愛旅行的工程師」部落格風格指南

這份指南整理自 thedayisthelastday.com 上已發佈的文章：達那 No.23、鬼澤157 No.27、台南三間飯店、享沐時光、峇里島系列。
語氣請搭配 `examples/` 裡的範文一起看。這份文件說明規則，範文示範實際的寫法。

---

## 1. 語氣與寫法

- **第一人稱，像在跟朋友聊天**。主詞常用「我」、「我們」，同行的人稱為「旅伴」、「男友」、「朋友們」。用使用者實際的稱呼，不要自己替換。
- **誠實**。優點、缺點都寫，抱怨也直接寫出來，例如「實在不便利」、「令人很生氣的是…」。之後常會接一句正面的話收尾，例如「但和旅伴都還是喜歡這次露營的回憶」。
- **寫具體細節**。要有時間（10：00 開放入營）、價格（台幣 $1800）、數字（海拔約 660 公尺、23 坪）、品牌和型號（KZM T250、屋脊六）。數字前後加半形空格。
- **加入當下的心情**，例如「有種美夢終於成真的感覺」、「不敢抱太大期望」、「又好氣又好笑」。
- **常用詞**：幸運、意外地、愜意、放空、慢活、CP 值、小確幸、極致放鬆、療癒、驚艷。每個詞在一篇文章裡只用一兩次，**不要堆砌**。
- **小幽默**：用括號補充一句，例如「（是的，這是個有玄關的房間！）」、「（花瓣是我們自備的…）」；或用全形波浪號「～」，例如「遠離 3C 嘛～」、「非～常遠」。
- **實用建議穿插在敘事裡**，例如「建議問清楚…」、「記得殺價可以從半價開始喊喊看！」。
- **不要寫的東西**：過度華麗的形容、成語堆砌、沒有根據的感受，以及「讓我們一起…」這類行銷腔。

### 段落節奏
- 一段 **1～3 句**，很少超過 4 句。
- **每 1～2 段放一組照片**，照片放在描述它的那段文字後面。
- 一篇文章大約 **1500～3500 字**（只算文字）。字數由使用者提供的素材量決定，不用硬湊到某個字數。

## 3. 各類型的文章結構

### A. 露營
1. 先放可重複使用區塊 `#480`（H2 標題「營地位置/交通/海拔/特色」），接著放 **📌 營區資訊清單**，大約 7～9 點：交通、海拔、設施、衛浴、價格、優缺點，**最後一點固定是「露營日期：YYYY/MM/DD-YYYY/MM/DD」**。缺點或重點用 `<mark>` 標出。
2. （選用）有分享菜單時，放可重複使用區塊 `#2365`（露營菜單）和菜單表格，欄位為「- ｜餐點｜材料」。
3. 分隔線，然後寫 **前言** 2 段：為什麼選這個營區、出發前的心情、第幾露。
4. **4～6 個小節**。每節的 H3 小標是**一整句帶情緒的話**，例如「擁擠的營位，是第二次搭 KZM T250 的一大挑戰！」，小標下面寫故事並配照片。
   常見的主題有：抵達與搭帳、營區風景、料理與愜意時光、意外事件或轉折、設施（衛浴、冰箱、洗手台）、撤收。
5. （選用）裝備開箱：放可重複使用區塊 `#2361`（帳篷體驗），再寫使用心得和優缺點。
6. 分隔線，接著寫 **推薦指數**：`<p><strong>營區名－我的推薦指數 9.2 ⭐️</strong></p>`，下面接一段總評。
7. **Google 地圖**。

### B. 住宿
1. 開頭放**重點清單**，有兩種寫法：
   - 舊寫法：一個段落，每行以 📌 開頭，用 `<br>` 換行，最後一點是「住宿日期：…」
   - 新寫法（享沐時光）：`wp:quote` 裡面放 `wp:list`
2. 分隔線，接著寫前言 1～2 段：為什麼訂這間、一句話總評。
3. 依照**入住動線**分節：抵達與大廳 → 房型 → 浴室 → 景觀 → 公共設施（溫泉、泳池）→ 餐飲 → 退房後。
4. 分隔線，寫總結一段：適合誰來、會不會回訪。
5. **Google 地圖**。

### C. 多日旅遊行程
1. 第一行寫 `旅遊時間：YYYY/MM/DD-YYYY/MM/DD`，接著寫前言 2～3 段。
2. **行前重點**：`wp:quote` 裡放有序清單，每點開頭是 `<mark><strong>重點：</strong></mark>`，後面接說明。
3. （如果有）其他相關文章的連結清單。
4. **費用表**：欄位為「- ｜價格（台幣）/ 人｜備註」，表格後面用一句 H3 總結總花費。
5. **每天一節**：H3 寫成 `DAY N－一句話亮點`，下面先寫 1～2 段敘事，再放行程表（「行程｜備註」，備註裡寫 ⭐️ 評分和心得），最後放照片。
6. 分隔線，寫總結一段，最後放小東西，例如伴手禮、濾芯對比照。

### D. 單一景點／主題文
前言用一個提問或一句結論開頭，例如「如果有人問我…我會毫不猶豫地回答」。接著用 H3 分節，或用 `<mark>重點：</mark>` 開頭的條列重點。結尾放一份「總結：XX 守則」清單和 Google 地圖。

## 4. 區塊語法（直接複製）

### 段落
```html
<!-- wp:paragraph -->
<p>內容</p>
<!-- /wp:paragraph -->
```

### 強調（mark）
顏色跟著這篇選的配色（見下方「H3 小標」）：
```html
<mark style="background-color:rgba(0, 0, 0, 0);color:#276783" class="has-inline-color">重點文字</mark>
```
mark 用來標**真正的重點或可以帶走的建議**，一篇用 3～8 處。不要每段結尾都放一句 mark 金句。

### H3 小標
**依照每篇文章的風格挑一組配色**，同一篇裡的小標和 `<mark>` 強調色要用同一組。挑好後在大綱裡告訴使用者用了哪一組。

| 配色 | 底色 / 字色 | mark 強調色 | 適合的文章 | 用過的文章 |
|---|---|---|---|---|
| 湖水藍 | `#b8e0e7` / `#276783` | `#276783` | 露營、山林、溪邊 | 鬼澤157 No.27 |
| 淺藍 | `#e0edf5` / `#327da9` | `#327da9` | 海島、海邊、多日旅遊 | 馬祖總覽（使用者自己挑的） |
| 米色 | `#ece4d9` / `#000000` | `#41a8bf` | 飯店、溫泉、日式或木質空間 | 享沐時光 |
| 其他 | 依照文章的照片色調自己搭配 | | 例如秋天的楓葉、櫻花季、夜景 | |

自己搭配顏色時要遵守：
- 用淺色當底色、深色當字色，字和底色的對比要夠，讀起來不吃力。
- **一律用 `style` 直接寫 hex 色碼**，不要用 `backgroundColor`、`textColor` 這種主題內建的顏色名稱。部落格搬家後的新主題沒有舊的 `medium-gray`，舊文章的灰底白字在新主題上只剩白色的字，完全看不到。
- 不要用白色字。

寫法（把兩個色碼換成選好的配色）：
```html
<!-- wp:heading {"level":3,"style":{"color":{"background":"#e0edf5","text":"#327da9"}},"fontSize":"small"} -->
<h3 class="wp-block-heading has-text-color has-background has-small-font-size" style="color:#327da9;background-color:#e0edf5">小標文字</h3>
<!-- /wp:heading -->
```
米色那組的舊寫法會在小標文字外面包一層 `<strong>`，要加粗可以照著加。

### 📌 資訊清單（露營、舊版住宿）
```html
<!-- wp:paragraph -->
<p>📌 第一點<br>📌 第二點<br>📌 露營日期：2026/03/14-2026/03/15</p>
<!-- /wp:paragraph -->
```

### 引用框裡的清單（住宿重點、行前重點）
```html
<!-- wp:quote -->
<blockquote class="wp-block-quote"><!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li>第一點</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>第二點</li>
<!-- /wp:list-item --></ul>
<!-- /wp:list --></blockquote>
<!-- /wp:quote -->
```
有序清單要把 `<!-- wp:list -->` 換成 `<!-- wp:list {"ordered":true} -->`，`<ul>` 換成 `<ol>`。

### 分隔線
```html
<!-- wp:separator -->
<hr class="wp-block-separator has-alpha-channel-opacity"/>
<!-- /wp:separator -->
```

### 表格
```html
<!-- wp:table -->
<figure class="wp-block-table"><table class="has-fixed-layout"><tbody><tr><td>-</td><td><strong>欄位</strong></td></tr><tr><td><strong>Day 1</strong></td><td>內容</td></tr></tbody></table></figure>
<!-- /wp:table -->
```

### Google 地圖
預設用不需要 API key 的嵌入網址，`q=` 後面放地點名稱並做 URL 編碼：
```html
<!-- wp:paragraph -->
<p><iframe src="https://www.google.com/maps?q=%E9%AC%BC%E6%BE%A4157%E9%9C%B2%E7%87%9F%E5%8D%80&output=embed" width="600" height="450" style="border:0;" allowfullscreen="" loading="lazy" referrerpolicy="no-referrer-when-downgrade"></iframe></p>
<!-- /wp:paragraph -->
```
如果使用者有提供 Google Maps「分享 → 嵌入地圖」的網址，就改用那個網址。

### 連結（參考【哈爾濱】八天七夜…懶人包＆避雷攻略那篇）
- **不要用 icon**（👉、➡️ 等），也**不要出現藍字連結**。連結顏色設定成和內文一樣的黑色。
- **文中引用其他文章**：用「XX請參考：」開頭，後面接**完整的文章標題**當連結文字，開新分頁：
```html
<!-- wp:paragraph {"style":{"elements":{"link":{"color":{"text":"#000000"}}}}} -->
<p class="has-link-color">四天三夜的完整行程與心得請參考：<a href="文章網址" target="_blank" rel="noreferrer noopener">【馬祖】完整文章標題</a></p>
<!-- /wp:paragraph -->
```
- **總覽連到每日文章**：DAY 小標本身就是連結，段落下方再放一行置中、粗體的「閱讀當日詳細圖文日誌」：
```html
<!-- wp:paragraph {"align":"center","style":{"elements":{"link":{"color":{"text":"#000000"}}}}} -->
<p class="has-text-align-center has-link-color"><strong><a href="文章網址" target="_blank" rel="noreferrer noopener">閱讀當日詳細圖文日誌</a></strong></p>
<!-- /wp:paragraph -->
```
  小標裡的連結顏色要和小標的字色一樣：在小標的 `style` 加 `"elements":{"link":{"color":{"text":"小標字色"}}}`，class 加 `has-link-color`。
- **每日文章**：不放「回到總覽」「上一篇／下一篇」這類按鈕。需要提到其他篇時，在文中用上面的引用格式。
- 還沒發佈的草稿，網址用 `https://thedayisthelastday.com/?p=文章ID`，發佈後會自動導到正式網址。

### 照片（佔位語法，由 `blog.py` 轉成區塊）
每個佔位要**單獨一行**，檔名寫旅程資料夾裡的原始檔名：
```
[[gallery: IMG_001.HEIC, IMG_002.jpg, IMG_003.jpg]]
[[media-text: IMG_004.jpg | 一兩句圖說，像在跟讀者指著照片講話。 | left]]
[[image: IMG_005.jpg | 替代文字]]
```
- `gallery` 放 **2～3 張**。同一個場景有 4～5 張時，可以放一組 4～5 張，但很少用。
- `media-text` 用在**一張照片配一兩句圖說**，例如貓咪來訪、狼狽的模樣。圖片位置在 left 和 right 之間輪流。
- `image` 只用在需要單張大圖的時候，例如推薦指數下面的那張。

### 廣告
- **不用在文章裡放廣告區塊**。網站搬家後改用 Google AdSense 自動廣告（透過 Site Kit 外掛載入），廣告會自動出現。
- 舊文章裡的 `<!-- wp:jetpack/wordads /-->` 是 WordPress.com 時期的 WordAds，現在網站沒有開啟 WordAds，**不要再插入**。
- 如果使用者之後提供 AdSense 廣告單元的代碼，再照舊文章的位置插入：大約在第 2 個小標前、文章中段、結尾前各放一個。

## 5. 分類與標籤
- 露營：分類用「露營」，再加上地區分類，例如「新竹露營」、「苗栗露營」、「桃園露營」、「台中露營」。
- 住宿：分類用「住宿體驗」和「國內旅行」（國外的話用「國外旅行」，再加上國家分類）。
- 國外：分類用「國外旅行」，再加上國家分類，例如「峇里島」、「泰國」、「亞庇沙巴」。
- 標籤 4～6 個，包括地點、營區或飯店名、主題（例如「露營體驗」、「櫻花露營」、「飯店體驗」、「旅遊心得」）。
- 實際有哪些分類，用 `blog.py site` 查詢，不要自己發明新的分類。
